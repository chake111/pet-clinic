# 宠物医院预约问诊系统

单家宠物医院自用的预约与问诊系统。语言：领域词汇以中文为准，代码标识符沿用英文列名。

**本系统角色统一用"医生"**：界面文案、README、数据库列注释采用同一称谓。

## Language

### 参与者

**宠物主人**:
拥有宠物并发起预约或问诊的人。
_Avoid_: 用户、患者、客户

**医生**:
院内提供诊疗的员工档案本身（表 `doctor`）；医生不能凭档案登录，需另有一个绑定它的后台账号。
_Avoid_: 兽医、宠物医生、医师。**例外**：仅在指本系统角色时统一用"医生"；引述他人研究（国外兽医诊所、兽医远程医疗、378 家兽医业务公司）、外部商业平台语境、以及国际固定术语（兽医—客户—动物关系 VCPR、兽医技术员 veterinary technician）里保留"兽医"——那些是术语不是称谓，批量替换前必须先分这两类。

**后台账号**:
院内人员的登录身份，携带一个角色；角色为 DOCTOR 时绑定唯一一份医生档案。
_Avoid_: 管理员账号、员工账号、登录用户

**管理员**:
后台账号的角色之一，负责账号、排班、公告等内容与秩序的维护，可查询预约及代宠物主人取消待接诊预约；不代医生接诊、结束就诊或写病历。
_Avoid_: 超级管理员、前台

### 诊疗主线

**预约单**:
宠物主人为一次到院门诊挂号的单据。
_Avoid_: 订单、挂号单、图文单

**号源**:
某位医生在某一天某一时段可接诊的容量，被预约单占用。
_Avoid_: 排班、时段

**排班时段**:
医院安排医生出诊的时间类别，分为上午（08:00–12:00）、下午（13:00–18:00）和夜间（18:00–22:00）。每条排班的实际起止时间可在所属范围内调整，开始时间须早于结束时间。
_Avoid_: 号源

**问诊会话**:
宠物主人与医生之间的图文咨询过程，免费发起、不限量。独立于预约单存在：不占号源、不建预约单、结束后也不补建关联。
_Avoid_: 图文单、在线问诊单、接诊窗口

**建议到院**:
医生在问诊会话内发出的一条提示，引导宠物主人另行挂号。它作为会话消息保留，不自动建立预约单或病历关联。
_Avoid_: 转诊、转诊建议、开单

**病历**:
一次到院就诊的诊疗记录，一张预约单至多一份**有效**病历；仅就诊中或已完成的预约可由所属医生填写、修订，后台不提供删除。
_Avoid_: 诊疗记录、处方

**就诊小结**:
医生结束问诊会话时留下的简短收尾说明；线上只给建议，不下诊断。
_Avoid_: 小结、结论

### 收尾与治理

**未到诊**:
已支付、过了就诊日仍待接诊的预约单的终态；已接诊预约继续由医生收尾，未支付预约走超时取消。
_Avoid_: 逾期未收尾、未就诊

**处置**:
管理员对整个问诊会话作出的治理动作（无效关闭 / 违规屏蔽），与会话的诊疗生命周期正交；非零处置后参与方视该会话不存在，管理员审计视图仍可见。
_Avoid_: 关闭

**屏蔽**:
管理员对单条问诊消息作出的治理动作，被屏蔽内容对参与方不可见。
_Avoid_: 删除

### 概念模型

**概念实体**:
概念结构层面建模的业务对象集合。系统字典不是概念实体，它是属性取值域的载体。
_Avoid_: 表

**物理表**:
关系模型落地后的表。物理表与业务概念不是一一对应关系；数量应按当前建表脚本与概念模型分别统计。

**业务联系**:
业务主体与对象之间的拥有、提交、编排、诊疗、维护或处置关系。首次创建表示一次对象建立事件；维护与处置表示对象生命周期内的参与，不要求参与者唯一。
_Avoid_: 外键、权限

### 视觉语言

**动作色**:
界面上表示"用户可以做这件事"的填充色，由品牌红里承白字仍达 4.5:1 的深一档 #d92549 承担（Rausch #ff385c 白字仅 3.5:1，只用于标识与图标）；它不表示任何业务状态。

**语义色**:
表示业务状态的颜色（进行中蓝、成功绿、待办橙、危险红、终止灰），只由状态胶囊和确有状态含义的元素使用。

**插画色**:
科室图标专用的颜色角色，用于多色图标内部的色块；不参与动作与状态语义，也不得复用动作色与语义色的色值。
_Avoid_: 品牌色、主题色
