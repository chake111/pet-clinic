===== 本轮修掉的脚本自身缺陷（非产品问题）=====
1. department.code 有唯一索引，脚本结尾又刻意保留"删除被拦截"的科室，
   固定编码重复跑会 400。改为每次运行带后缀 rc1_/rc2_ + 运行戳。
2. 排班同样有（医生+日期+时段）约束，改为在 2099-11 内挑一个空闲日期。
3. 分页用例按"本次 pet_id 的最小 id"取最旧会话；排序是
   last_message_time DESC, id DESC，重复运行后上一轮批次有更小的 id，
   该 id 不会落在最后一页。改为按批次取全局最旧（user_id+doctor_id+symptom='旧会话'）。
