## 卡在哪

自动部署在首次成功前连续失败 4 次，对应 3 类 `production` environment 配置报错（原始摘录见 [failures.txt](test-evidence/20261121-deploy/failures.txt)）：

1. **有 secret 为空（Run `44871613018`，05:35 UTC）**：`ssh` 命令打印用法说明并以 `exit code 255` 退出（推断：疑似有 secret 为空；日志中 `SSH_HOST` 与 `SSH_USER` 展开为空串）。
2. **主机指纹不匹配（Run `44873053843`，05:54 UTC）**：报错 `Host key verification failed.`（`exit code 255`），`SSH_KNOWN_HOSTS` 与目标服务器公钥指纹不一致。排查需按报错字面意思用 `ssh-keyscan -H <host>` 重新核对并更新 `SSH_KNOWN_HOSTS`。
3. **部署路径填成文件路径（Run `44873481195`、`44875227449`，06:00 / 06:22 UTC）**：`DEPLOY_PATH` 曾经填成 `compose.yaml` 的文件路径，导致远程执行 `cd "$DEPLOY_PATH"` 报 `bash: line 1: cd: ***: Not a directory`（`exit code 1`）。
